Bootstrap Layout Cases

คลัง case จัด layout ด้วย Bootstrap utility ตาม design_guideline.md §4 · §8 · §9 · §13. แต่ละ case = "เมื่อไหร่ใช้" + demo + markup copy ได้. เรียกใช้/เพิ่ม case ผ่าน skill bootstrap-guide.

Case 1 · Section spacing (แบ่งโซน)

.py-4 / .mb-4

เมื่อไหร่: มีหลายโซนในหน้าเดียว (summary → toolbar → content) อยากเว้นให้อ่านเป็นก้อน. กฎ §4: section gap 16–24 = py-4 (1rem) หรือ mb-4 · internal ≤ external (padding ในการ์ด ≤ ช่องว่างนอก).

โซน A — summary · py-4
โซน B — toolbar · py-4
โซน C — content · py-4
<div class="container-xxl px-4 pt-3 pb-5">
  <section class="mb-4"> ... summary ... </section>
  <section class="mb-4"> ... toolbar ... </section>
  <section>           ... content ... </section>
</div>
ใช้ margin (mb-4) คั่น section · ใช้ padding (py-*) เมื่ออยาก "หายใจ" ภายในโซนที่มีพื้นหลัง. ❌ อย่าใช้ทั้งคู่ซ้อนจนช่องว่างบวม.

Case 2 · Toolbar P1 (tabs ซ้าย · action ขวา)

.d-flex .justify-content-between .align-items-center

เมื่อไหร่: หน้า list/ledger (§13 P1) — แถบเครื่องมือ: tabs/filter ชิดซ้าย, search+primary ชิดขวา, บรรทัดเดียว. sticky ตอน scroll. mobile = พับลงเป็นสองแถว (flex-wrap).

<div class="d-flex justify-content-between align-items-center flex-wrap gap-3">
  <div class="bb-tabs"> ...tabs... </div>          {# ซ้าย #}
  <div class="d-flex align-items-center gap-2">    {# ขวา #}
    ...search... ...primary button...
  </div>
</div>
sticky: ครอบ toolbar ด้วย class="position-sticky top-0" + style="z-index:10" (guideline §13 กฎรวม).

Case 5 · Table → Card stack (mobile)

.d-none .d-md-block / .d-md-none

เมื่อไหร่: ตารางกว้างอ่านยากบนมือถือ (§9 กลยุทธ์ card stack) — desktop โชว์ table, mobile สลับเป็น card ต่อแถว.

≥md — <table class="bb-table"> (แถวนอน)
<md — card ต่อแถว (label:value ในการ์ด)
<table class="bb-table d-none d-md-table"> ...rows... </table>   {# desktop #}

<div class="d-md-none d-flex flex-column gap-2">                {# mobile #}
  {% for r in rows %}
  <div class="bb-card"><div class="bb-card-body">
     <div class="d-flex justify-content-between"><span>ทะเบียน</span><b>{{ r.plate }}</b></div>
     ... label:value รายบรรทัด ...
  </div></div>
  {% endfor %}
</div>
ทางเลือกอื่นตาม §9: horizontal scroll (overflow-x:auto) หรือ ซ่อนคอลัมน์รอง + expandable row — เลือกตามจำนวนคอลัมน์.
