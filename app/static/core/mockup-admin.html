Design decisions

Week navigator = hero

  • หัวการ์ด = วันที่เลือก + ปุ่ม วันนี้ + bb-select เปิดปฏิทิน (ใช้ bb_daterange calendar ได้)
  • แถบ 7 วัน = pill เลือกได้ · วันนี้ขอบ accent · วันเลือก = พื้น accent · badge นับจำนวนจอง ต่อวัน (มือถือเลื่อนแนวนอน)

Layout = day-driven workspace

  • KPI strip (.bb-kpi.is-ghost) สรุปวันที่เลือก: รอจัดรถ · อนุมัติแล้ว · รถใช้งาน · รถว่าง
  • ซ้าย = รายการจอง (filter tabs + booking item) เหนือ การเดินทาง (เที่ยวที่จัดรถแล้ว) · ขวา = การใช้รถ sticky grid
  • booking item: เวลา-rail · ชื่อ+subbudget+badge งานด่วน/รวมเที่ยว · ปลายทาง · meta (คน/คนขับ) · ปุ่มเปลี่ยนตามสถานะ (อนุมัติ / ย้อนสถานะ / แก้ไข)

Modal — responsive + reuse

  • 1 component .bb-modal — desktop กลางจอ 500px · mobile bottom sheet · body = bb-summary + select รถ/คนขับ + bb-seg (ส่วนกลาง/กอง/ตัว) + budget bar
  • swap / ส่งซ่อม / ย้อนสถานะ = shell เดียวกัน เปลี่ยนแค่ body

Component reuse

  • ของกลางที่ใช้: bb-card · bb-kpi · bb-tabs · bb-btn · bb-badge · bb-status · bb-summary · bb-seg · bb-statbar · bb-modal · bb-select · bb-field · bb-avatar · bb-icon-btn
  • ใหม่เฉพาะหน้านี้ (mk-* → จริงเป็น va-*): week strip · booking item · trip row · vehicle tile · budget bar
