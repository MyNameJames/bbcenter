Design decisions + pattern

Desktop table — 11 คอลัมน์ · horizontal scroll (ไม่บีบ)

  • รถ / คนขับ แยกคอลัมน์ — รถ = ทะเบียน · คนขับ = ชื่อต้น (ไม่มีนามสกุล)
  • ผู้จอง sub-line เหลือเฉพาะ subbudget (กองสนับสนุนฯ / งานโภชนาการ…) ไม่แสดงประเภทงบ
  • เติมน้ำมัน กลับมาเป็นคอลัมน์ — แสดงแค่ icon fuel · hover/กด = tooltip "เติมน้ำมัน · เลขไมล์ NNN"
  • ตาราง min-width:1080px + white-space:nowrap → เลื่อนแนวนอน ไม่บีบ col

Mobile — card list · trip-summary pattern

  • ตาราง → .bb-card · head = checkbox+BK + สถานะ · foot = ปุ่มเต็มกว้าง (เปลี่ยนตามสถานะ)
  • tabs = horizontal scroll (ทั้ง desktop + mobile, ไม่บีบ)

Modal — responsive

  • Desktop = ขึ้นกลางจอ (.bb-modal) · Mobile = bottom sheet (drag handle)
  • header subtext = BK + ช่วงเวลาเดินทาง · body = trip-summary pattern (เหมือน card)
  • title "บันทึกเลขไมล์กลับ" → อีกฝั่งแสดง เลขไมล์ออกล่าสุด (เหมือนหน้า driver)

🔖 Trip-summary pattern (เก็บไว้ใช้ซ้ำ)

ใช้: mobile card body · modal body
┌──────────────────────────────────────┐
│ [ผู้เดินทาง]  …ชิดขวา…  [subbudget] │  ← .m-trip-sum-top
│ [ทะเบียน] (คนขับ) → [สถานที่ไป]    │  ← .m-trip-sum-route
└──────────────────────────────────────┘
class: .m-trip-sum > .m-trip-sum-top (-name | -budget) + .m-trip-sum-route (b=ทะเบียน)
