5 · ⛔ จุดที่เปลี่ยน token อย่างเดียวยังไม่จบ

CSS เดิมใช้ --bb-accent-i ตัวเดียวทำ 3 หน้าที่ (ปุ่มหลัก + ลิงก์ + active) — พอแยกเป็น ink/เขียวแล้วต้องแตกทีละจุด ในไฟล์ components.css ตอน batch 1-2
จุดCSS ตอนนี้token ล้วนจะได้ต้องเป็น (batch 1-2)
.bb-btn.is-pribg: accent-i อนุมัติ อนุมัติ ถูกสีแล้ว · เหลือ pill
.bb-btn.is-ghostcolor: accent-i ดูรายละเอียด ดำ = ไม่เหมือนลิงก์ ดูรายละเอียด accent-dk
.bb-tab.is-oncolor + border-bottom ทั้งหมด ทั้งหมด ผ่าน — active = ink
.bb-tab.is-on .bb-tab-countbg: accent-bg + color: accent-h 24 24 count ตาม tab = ink
.bb-table thead thcolor: accent-i ผู้ขอ แย่ง attention กับ cell ผู้ขอ หัวตาราง = mut
.bb-input:focusborder: accent + ring 2.38:1 ตก ink + ring ดำ
.bb-pg.is-onbg: accent-i 1 1 ผ่าน — เหลือ pill
.bb-badge.is-accentbg: accent-bg + color: accent-h ใหม่ 3.4:1 ตก ใหม่
