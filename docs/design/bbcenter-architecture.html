▸ Layer 2 — Authentication

🔐 Flask-Login · Session Manager
login_view = 'auth.login' — ทุก route ที่มี @login_required จะถูก redirect มาที่นี่ก่อน
1รับ username + password จาก form
2ส่งไปยืนยันที่ LDAP / Active Directory
3ถ้า valid → หา User ใน DB, ถ้าไม่มี → สร้างใหม่อัตโนมัติ
4login_user() → session ลง Browser (TTL 8 ชั่วโมง)
🏢 LDAP · Active Directory (ad_utils.py)
ตรวจสอบ credentials กับ domain server องค์กร
คืนค่า: full_name, email, department

check_ad_login() python-ldap
↓ Authenticated Request
