5. Open Decisions — ต้องเลือก
🤔 Mobile Card Style
Option A — Full card
เห็นข้อมูลครบ (dest+booker+car) แต่กินพื้นที่
Option B — Compact horizontal (time col + info col)
compact กว่า เหมาะถ้ามีหลาย event
🤔 Calendar Collapse Animation
Option 1 — max-height transition
เรียบง่าย ไม่มี glitch
Option 2 — transform + opacity (slide up + fade)
smooth กว่า แต่ซับซ้อนขึ้น
Option 3 — ไม่มี animation (instant)
เร็วที่สุด ไม่มี delay
