# doc/ — เอกสารที่ทำเสร็จแล้ว

> โฟลเดอร์นี้เก็บเอกสารสำหรับ feature หรืองานที่ **completed** แล้ว

---

## วิธีใช้

เมื่อทำงานชิ้นใดเสร็จ ให้สร้างไฟล์ `.md` ในโฟลเดอร์นี้
แนะนำตั้งชื่อไฟล์ในรูปแบบ: `YYYY-MM-DD_ชื่องาน.md`

ตัวอย่าง:
```
doc/
├── 2026-04-06_database-schema.md
├── 2026-04-06_vehicle-booking-flow.md
└── ...
```
