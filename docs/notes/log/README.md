# log/ — งานที่ยังค้างอยู่ (In Progress)

> โฟลเดอร์นี้เก็บ log ของงานที่ **ยังไม่เสร็จ** หรืองานที่กำลังดำเนินการอยู่

---

## วิธีใช้

ทุกครั้งที่เริ่มทำงาน ให้สร้างหรืออัปเดตไฟล์ `.md` ในโฟลเดอร์นี้
เมื่องานเสร็จแล้ว ให้ย้ายไปที่ `doc/` แทน

แนะนำตั้งชื่อไฟล์ในรูปแบบ: `YYYY-MM-DD_ชื่องาน.md`

---

## Template สำหรับ log ใหม่

```markdown
# [ชื่องาน]

> สถานะ: 🔄 In Progress
> เริ่มต้น: YYYY-MM-DD
> อัปเดตล่าสุด: YYYY-MM-DD

## เป้าหมาย
- ...

## สิ่งที่ทำไปแล้ว
- [ ] ...

## สิ่งที่ยังค้างอยู่
- [ ] ...

## หมายเหตุ / ปัญหาที่พบ
- ...
```
