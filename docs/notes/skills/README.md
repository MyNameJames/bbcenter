# Workflow Skills

รวบรวม workflow templates และ process checklists สำหรับงานพัฒนา BBCenter

## วิธีใช้
- แต่ละ skill คือไฟล์ Markdown หนึ่งไฟล์
- ตั้งชื่อไฟล์เป็น `[slug].md` เช่น `add-feature.md`, `bug-fix.md`
- เรียกใช้โดย copy prompt หรือ reference ให้ Claude ทำตาม

## ไฟล์ใน folder นี้
| ไฟล์ | คำอธิบาย |
|------|----------|
| _(ยังไม่มี)_ | เพิ่ม skill แรกได้เลย |
